# Plan: Configure Ngrok URL for API Backend

## Problem
The frontend is currently hardcoded to connect to `http://localhost:5000`. The user has deployed the backend on ngrok at `https://59c9-156-203-155-16.ngrok-free.app` and needs to configure the frontend to use that URL.

## Solution
Use Vite environment variables to make the API base URL configurable.

### Step 1: Create `.env` file in project root
Create a `.env` file with:
```
VITE_API_BASE_URL=https://59c9-156-203-155-16.ngrok-free.app
```
**Why `VITE_` prefix?** Vite only exposes environment variables that start with `VITE_` to the client-side code.

### Step 2: Update `src/services/api.ts`
Replace line 10:
```typescript
export const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || "http://localhost:5000";
```
- This reads the ngrok URL from the environment
- Falls back to localhost for development if `.env` is missing

### Step 3: Add `.env` to `.gitignore`
The current `.gitignore` does not explicitly exclude `.env` files. Add the following line:
```
.env
```
To prevent accidentally committing the environment file.

### Step 4: Restart the dev server
After changes, stop and restart `npm run dev` to load the new environment variable.

## Notes
- The ngrok URL uses HTTPS, which is compatible with Vite dev server
- The API server must accept requests from the Vite dev server origin (CORS)
- If the backend requires CORS configuration, ensure it allows requests from `http://localhost:8080` (Vite default) or the deployed frontend URL
